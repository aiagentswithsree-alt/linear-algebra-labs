# Linear Algebra Labs

Interactive, learn-by-doing labs that follow 3Blue1Brown's *Essence of Linear Algebra* series.
Each lab turns one chapter into short missions: **see the problem → predict → try it → learn the maths**.

## Labs

| Chapter | Lab | Concepts |
|---|---|---|
| 1 | [Vectors](ch01-vectors/index.html) | Coordinates, vectors as arrows and lists, vector addition, scalar multiplication, position vs movement, 3D |

## How to use

Open `index.html` (chapter list) or `ch01-vectors/index.html` in any browser. No install or internet needed apart from web fonts.
Progress is saved in your browser.

## Chapter 1 missions

1. **Find the parcel**: coordinates (video 2:41–3:56)
2. **Command the robot**: vector = length + direction (0:30–0:44, 3:22–3:48)
3. **Combine two moves**: vector addition (4:36–6:45)
4. **Stretch, shrink, flip**: scalar multiplication (6:54–8:00)
5. **Fix the broken command**: position vs movement (goes beyond the video)
6. **Prove it**: randomised challenge, explain-why questions, 3D extension

Source video: [Vectors | Chapter 1, Essence of linear algebra](https://www.youtube.com/watch?v=fNk_zzaMoSs) by 3Blue1Brown.
